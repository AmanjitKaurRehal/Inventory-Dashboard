
 
   Inventory Dahsboard : Real-Time Inventory Insights for Smarter Decisions

1. Short Description / Purpose
    
   An interactive Power BI dashboard designed to monitor inventory performance, stock availability, inventory valuation, turnover rates, 
   and sales trends. The solution provides real-time visibility into inventory operations through KPI tracking, category analysis, 
   regional performance monitoring, and product-level insights, enabling businesses to optimize stock levels, improve operational 
   efficiency, and support informed decision-making.

2. Core Technologies

   Power BI Desktop- Dashboard development and visualization.
                    Interactive reporting and data modeling.
                    
   Power Query (M Language) - Data extraction, cleaning, and transformation.
                              Data preparation before loading into the model.
                              
   DAX (Data Analysis Expressions) - KPI calculations and business metrics.
   
   Measures such as- Total Revenue,Inventory Value,Inventory Turnover,Days of Inventory on Hand (DOH),Stock Status.
   
   📊 Data Modeling - Star Schema / Relational Data Model among table inventory,Date.Realtionship established between the tables with 
      cross-filtering and aggregation.
      
   📈 Visualizations Used -KPI Cards,Inventory Turnover-Clustered Column Chart,Stock Overview by Month-Bar Charts,Inventory Value by 
    Category-Total Units Sold by Region-Table/Matrix Visual.
    
   🎨 Advanced Features- Custom SVG Icons using DAX 
                       Dynamic Stock Status indicators
                       In Stock / Low Stock / Out of Stock badges
                       Conditional Formatting
                       Status highlighting
                       KPI color indicators
                       Interactive Filtering
                       Visual cross-filtering and cross-highlighting

3. Data Source

   Source - https://datachy-2.kit.com/inventor
   Inventory and Sales Management Dataset containing product, inventory, sales, category, and store-level transactional data. The data 
   is modeled to support inventory valuation, stock monitoring, turnover analysis, sell-through measurement, and operational reporting 
   through interactive Power BI dashboards.

4. Feature and Highlights

   💰 Measures Inventory Value
 
    Displays the total value of inventory on hand ($997M).
    Helps understand how much capital is tied up in inventory.

   📈 Tracks Revenue and Sales Performance

    Shows total revenue generated ($495M).
    Monitors units sold and sales trends over time.

   🔄 Analyzes Inventory Efficiency

    Calculates Inventory Turnover (12.43), indicating how quickly inventory is sold and replenished.
    Measures Days of Inventory on Hand (DOH) (59 days), showing how long inventory is expected to last.
   
   🌍 Compares Performance Across Regions

    Visualizes units sold by region (East, South, North, West).
    Helps identify high-performing and underperforming locations.
    
    Organizations use this dashboard to
    
    ✅ Prevent stockouts and lost sales
    
    ✅ Reduce excess inventory and carrying costs
    
    ✅ Improve inventory planning and replenishment
    
    ✅ Optimize warehouse and supply chain operations
    
    ✅ Track inventory performance in real time
